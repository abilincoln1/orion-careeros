# Shared Libraries (Reserved -- Not Yet Implemented)

Placeholder for future product-agnostic utility libraries that more than
one ORION product needs (e.g. shared validation helpers, currency/date
formatting, pagination helpers). Nothing lives here yet because CareerOS
is still the only product and has not needed anything beyond what
`platform/kernel` already provides. Do not add code here until a second
consumer actually exists -- premature sharing is its own form of
unnecessary complexity (see docs/TechnicalDebt.md).
