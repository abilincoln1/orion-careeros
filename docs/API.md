# CareerOS API Reference -- Sprint 1

Full interactive documentation is auto-generated by FastAPI and served at:

- Swagger UI: `http://localhost:8000/docs`
- ReDoc: `http://localhost:8000/redoc`
- Raw OpenAPI schema: `http://localhost:8000/openapi.json`

This document summarizes the Sprint 1 surface; treat `/docs` as the
canonical, always-current reference once the stack is running.

All endpoints are namespaced under `API_V1_PREFIX` (default `/api/v1`).

## Health

| Method | Path              | Auth | Purpose                                   |
|--------|-------------------|------|--------------------------------------------|
| GET    | `/health`         | none | Human-friendly service summary            |
| GET    | `/health/live`    | none | Liveness probe (process is up)            |
| GET    | `/health/ready`   | none | Readiness probe (checks DB connectivity)  |

`/health/ready` returns HTTP 503 with `{"status": "not_ready", ...}` if the
database is unreachable.

## Auth

| Method | Path                | Auth           | Purpose                              |
|--------|---------------------|-----------------|---------------------------------------|
| POST   | `/auth/register`    | none            | Create a new user account             |
| POST   | `/auth/login`       | none            | Exchange email+password for tokens    |
| POST   | `/auth/refresh`     | none (token)    | Exchange a refresh token for new pair |
| GET    | `/auth/me`          | Bearer access   | Return the authenticated user         |

### `POST /auth/register`
Request:
```json
{ "email": "abi@example.com", "password": "supersecret1", "full_name": "Abiodun Adeniran" }
```
Response `201`:
```json
{ "id": "...", "email": "abi@example.com", "full_name": "Abiodun Adeniran",
  "is_active": true, "is_superuser": false, "created_at": "..." }
```
`409` if the email is already registered.

### `POST /auth/login`
Request:
```json
{ "email": "abi@example.com", "password": "supersecret1" }
```
Response `200`:
```json
{ "access_token": "...", "refresh_token": "...", "token_type": "bearer" }
```
`401` on bad credentials, `403` if the user is inactive.

### `POST /auth/refresh?refresh_token=...`
Response `200`: new `access_token` + `refresh_token` pair. `401` if the
refresh token is invalid, expired, or not of type `refresh`.

### `GET /auth/me`
Header: `Authorization: Bearer <access_token>`
Response `200`: the current user (same shape as register). `401` if the
token is missing/invalid/expired, or the user is inactive.

## Error format

All handled errors return:
```json
{ "error": { "code": 404, "message": "..." } }
```
Validation errors (`422`) additionally include `details` with field-level
Pydantic error info.

## Versioning

Every endpoint is under `/api/v1`. Breaking changes in future sprints
introduce `/api/v2` rather than mutating existing contracts, per the "API
First" principle.
