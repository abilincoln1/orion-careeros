| TD-R06 | Bug (found via live Docker run) | `docker compose up --build`, run by the user on their actual Windows/Docker Desktop machine, crash-looped `careeros_backend` with `pydantic_settings.sources.SettingsError` / `JSONDecodeError` on `CORS_ORIGINS`. Reproduced the exact crash and confirmed the fix locally (Python, no Docker needed, since the bug is in pydantic-settings' env-parsing, not Docker itself) before reporting fixed; full backend test suite (12/12) re-run and still passing. **Confirmed inside an actual container**: the user re-ran `docker compose up --build` and the backend started cleanly with no crash loop -- see TD-R07. |
| TD-R07 | Verification gap (was TD-007) | `docker compose up --build` had never been executed end-to-end to completion; the equivalent verification (embedded PostgreSQL, live `uvicorn` process, direct HTTP calls) proved the application + database integration but not the container build, inter-container networking, or Docker's own `HEALTHCHECK` directive. | User ran `docker compose up --build` a second time after the TD-R06 fix.
